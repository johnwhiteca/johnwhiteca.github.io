# johnwhite.ca — Astro homepage starter

## Start

```bash
npm install
npm run dev
```

Visit http://localhost:4321. Run `npm run build` for production output in `dist/`.

## Before publishing

- Replace the portrait placeholder with an actual photo.
- Replace the illustrative gradient hero with a licensed photograph if desired.
- Verify the contact email (`hello@johnwhite.ca`) and change it to a real address.
- Review all text and dates.
- The mockup screenshot is included at `public/images/design-reference.png` as a visual reference only; the website does not use it as a background.

This is a standalone starter, not a modification of the existing repository.
